Название: Тройной удар (домашнее задание №2)
Автор: Сайкин Михаил Сергеевич, бТИИ-261

Описание задачи
Программа принимает три целых числа A, B, C — уровни силы героев A, B и C. Её цель — определить, активируется ли специальная способность «Тройной удар».
Способность «Тройной удар» активируется только если уровень силы каждого из трёх героев кратен трём (то есть делится на 3 без остатка). Если хотя бы у одного героя сила не кратна трём — способность не срабатывает.
Условие активации реализовано выражением: (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)
